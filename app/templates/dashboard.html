Loading agent configuration…

Set SENTINELX_AGENT_TOKEN in the server environment and restart SentinelX. On the monitored Windows host, set the same value in the current PowerShell session, then run:

$env:SENTINELX_AGENT_TOKEN = "your-local-agent-token"
.\app\host_monitor\Watch-SentinelXSecurityLog.ps1

Collects Security events 4624/4625 only. Read access to the Security log may require administrator membership. Transport is restricted to loopback; the token is never shown here.

Active defense · human approval required

The local dashboard can execute evidence-linked Windows Firewall actions only after you type the exact public IP and explicitly approve it in the confirmation dialog. The SentinelX server must run elevated. A matching rollback removes only the SentinelX-managed rule.

flask --app run.py approve-remediation <recommendation-id>
flask --app run.py remove-remediation <recommendation-id>

Firewall actions change the local host and may disrupt access. Only the exact public IP in a stored recommendation is eligible; no shell is used. Browser actions are loopback-only, and approvals, outcomes, and rollback are recorded in the tamper-evident audit chain.
